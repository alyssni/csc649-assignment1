# User Stories

1. As a customer, I want to browse party backdrop templates and decoration services, so that I can find designs that match my preferred party theme.
2. As a customer, I want to request customised backdrop designs and submit booking requests, so that I can arrange decorations that suit my needs.
3. As a customer, I want to view collaborating vendors and their services, so that I can explore different options for my party.
4. As an administrator, I want to manage backdrop templates, decoration services, and vendor information, so that the platform displays up-to-date information.
5. As an administrator, I want to review customer booking requests, so that I can manage bookings and coordinate decoration services.
